## 🎮 專案簡介：經典方塊遊戲控制台
本專案為一個基於純前端技術（HTML5 + CSS3 + Vanilla JavaScript）開發的網頁經典遊戲引擎。
* **Canvas 繪圖驅動：** 使用輕量高效的 HTML5 `<canvas>` 元件，並透過 JavaScript 實作遊戲生命週期與刷新機制。
* **響應式 UI 排版：** 整合 Flexbox 容器架構，清晰呈現分數看板、關卡難度與系統控制器。
